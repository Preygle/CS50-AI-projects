# Project 6: Attention

## My Learning Journey

This felt like looking into the brain of an AI.
Seeing the attention maps was trippy. You can literally see one "Attention Head" focusing on the *next* word, another acting like a grammar checker, and another linking pronouns to nouns.

It demystified "Transformers" for me. They aren't magic; they are just massive calculators looking for relationships between words.

The coolest part was seeing how "context" changes everything. Changing one word in a sentence shifts the attention weights completely, proving that the model "reads" the whole sentence contextually, not just left-to-right.
