# Project 4: Shopping

## My Learning Journey

This was a great intro to the `scikit-learn` library. The heavy lifting of the algorithm is done by the library, so the challenge here was **Data Engineering**.

I learned that computers are dumb—they don't know what "June" is. I had to manually map months to `5`, `6`, etc., and convert booleans to integers. It showed me that 80% of Machine Learning is just cleaning up the messy data so the model can eat it.

Also, balancing Sensitivity and Specificity was tricky. Tweaking k (neighbors) changes the balance. It was a good lesson in "there is no perfect model," just trade-offs.
