# Project 3: Crossword

## My Learning Journey

This was one of the most "magical" projects. You give it a shape and a list of words, and it fits them together perfectly.

I gained a deep appreciation for **heuristics**. Without MRV and LCV, the algorithm would sometimes take *forever* to solve a large puzzle. With them, it's almost instant. It taught me that sometimes being "smart" about *which* guess you make is more important than how fast you can guess.

The **AC-3 algorithm** was also a cool concept—propagating constraints. "If A changes, B might change, which means C might change..." It felt like setting up dominoes.
