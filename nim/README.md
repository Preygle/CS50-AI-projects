# Project 4: Nim

## My Learning Journey

This was my favorite "Zero to Hero" moment. Watching the AI start by making random, nonsensical moves and then, after a few seconds of training, becoming completely unbeatable was wild.

The concept of **delayed reward** was the key takeaway. The AI realizes that a specific move *now* doesn't give points immediately, but it leads to a state where winning is inevitable.

It also made me realize how powerful simple trial-and-error is when you can run it 10,000 times a second. It basically "solved" the game by brute-force experiencing every possibility.
