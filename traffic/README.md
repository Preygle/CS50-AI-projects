# Project 5: Traffic

## My Learning Journey

Training a model that can look at a blurry photo and say "That's a 30km/h Speed Limit sign" with 98% accuracy is mind-blowing.

I spent *way* too much time experimenting with the layers.
- "What if I add more filters?" -> Training gets slow.
- "What if I remove the Dropout?" -> It memorizes the training data but fails the test (overfitting).

It taught me that Deep Learning is as much an art as it is a science. You're tuning knobs (hyperparameters) to find the sweet spot where the AI learns general concepts, not just pixel-perfect memorization.
