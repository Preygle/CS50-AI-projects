# Project 1: Knights

## My Learning Journey

This was my first real brush with formal logic programming. It felt like turning a riddle into math.

The hardest part was faithfully translating the recursive nature of the lies. If a Knave says "I am a Knight," that statement is *False*. Meaning the reality is NOT "I am a Knight". It gets brain-bending fast.

I learned that you can't just programmed explicit `if-else` rules. You have to describe the *universe* of rules and let the computer test the valid states. It’s declarative programming vs imperative. Instead of telling the computer *how* to find the answer, I told it *what* the rules are and asked "What world satisfies this?"
