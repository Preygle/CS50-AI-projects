# CS50 AI with Python Certification

Welcome to my **Harvard CS50 AI** portfolio!

This repository contains the 12 projects I built to tackle the fundamental problems of Artificial Intelligence. From basic search algorithms to deep learning neural networks, each project implements a core AI concept.

I've documented my journey and the technical details for each project below.

---

## Projects Overview

### Week 0: Search
Finding a solution to a problem, like a navigator finding the shortest route.
- **[Degrees](Degrees/README.md)**: Using Breadth-First Search (BFS) to find the Six Degrees of Kevin Bacon.
- **[Tic-Tac-Toe](tictactoe/README.md)**: An unbeatable AI using the Minimax algorithm.

### Week 1: Knowledge
Representing information and drawing inferences from it.
- **[Knights](knights/README.md)**: Solving "Knights and Knaves" logic puzzles using Propositional Logic.
- **[Minesweeper](minesweeper/README.md)**: An AI that plays Minesweeper using Knowledge Representation and Inference rules.

### Week 2: Uncertainty
Dealing with uncertain events and probability.
- **[PageRank](pagerank/README.md)**: Implementing Google's algorithm to rank web pages using Random Surfer models and Iterative formulas.
- **[Heredity](heredity/README.md)**: Assessing the likelihood of genetic traits using Bayesian Networks.

### Week 3: Optimization
Finding not just *a* solution, but the *best* or *valid* solution among many.
- **[Crossword](crossword/README.md)**: Generating crossword puzzles using Constraint Satisfaction Problems (CSP) and backtracking search.

### Week 4: Learning
 Improving performance based on data and experience.
- **[Shopping](shopping/README.md)**: Predicting customer purchases using k-Nearest Neighbors (k-NN).
- **[Nim](nim/README.md)**: An AI that teaches itself to play Nim using Q-Learning (Reinforcement Learning).

### Week 5: Neural Networks
 Modeled after the human brain to recognize patterns.
- **[Traffic](traffic/README.md)**: A Convolutional Neural Network (CNN) using TensorFlow to identify traffic signs in images.

### Week 6: Language
 Processing and understanding natural language (NLP).
- **[Parser](parser/README.md)**: Breaking down English sentences into logical structures using Context-Free Grammars (CFG).
- **[Attention](attention/README.md)**: Using BERT to predict masked words and visualize Attention Heads in language models.
