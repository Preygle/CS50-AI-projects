# Project 6: Parser

## My Learning Journey

Linguistics is harder than it looks. English is a messy language.
"I saw the man with the telescope."
- Did I use a telescope to see him?
- Or did the man have a telescope?

Writing the CFG rules forced me to think about the *structure* of language, not just the words. The computer takes things literally. If I didn't write a rule for "Adjective Noun", it would crash on "Blue book".

I learned that while CFGs are powerful, they are brittle. Sarcasm, slang, and poetry break these rigid rules instantly. But for formal sentences, it's a powerful way for a machine to understand "Who did what to whom."
